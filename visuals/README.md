# Visuals Addons

ESP, chams, graphics mods, camera tools, HUD, and cosmetic addons.

| File | Description |
|------|-------------|
| `3d china hat.lua` | 3-D china hat ESP |
| `3dfinalv2.lua` | Final v2 reimplementation of 3-D hat ESP |
| `china_hat_v2.lua` | Updated china hat with colour customisation |
| `simple china hat.lua` | Minimal china hat — low overhead |
| `Fake Position.lua` | Fake position visual — shows predicted/real positions |
| `Fake Position fixed.lua` | Fixed version of fake position visual |
| `desync_visuals.lua` | Ghost chams at desync/server position (see also `ragebot/`) |
| `CinematicCamera.lua` | Cinematic camera mode with smooth transitions |
| `RealisticGraphics.lua` | Lighting & atmosphere overrides for realistic look |
| `UltraRealismMaster.lua` | Master graphics overhaul: shadows, bloom, DoF, SSAO |
| `VolumetricGodRays.lua` | Volumetric god-ray post-processing effect |
| `SurrealFX.lua` | Surreal / psychedelic visual effects |
| `HeavyRain.lua` | Weather — heavy rain particle system |
| `hud.lua` | Custom in-game HUD overlay |
| `hud hider.lua` | Hides the default Roblox / game HUD |
| `ShapeAddon.lua` | Draws custom shapes in 3-D space |
| `animations.lua` | Custom animation overrides / replacers |
| `dahood_skin_changer.lua` | In-game character skin changer for Da Hood |
| `custom ui.lua` | Custom Linoria UI theme / layout |
| `dynamic_menu_example.lua` | Example of a dynamic Linoria menu |
| `boombox.lua` | Boombox visual + sound player |
| `face camera lock.lua` | Locks character to always face the camera |
