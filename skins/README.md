# Skins Addons

Skin changers and skin ID dumpers.

| File | Description |
|------|-------------|
| `unnamed_skin_changer.lua` | Full skin changer integrated with the Unnamed API — swap character appearance in-game |
| `dahood_skin_changer.lua` | Da Hood-specific skin changer (also in `visuals/` for context) |
| `skin_dumper.lua` | Dumps all available skin/asset IDs to console or file |
| `skindump.lua` | Lightweight skin ID dump utility |
