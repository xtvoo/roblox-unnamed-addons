# Utility Addons

Quality-of-life, loaders, AFK tools, avatar tools, vehicles, and miscellaneous scripts.

| File | Description |
|------|-------------|
| `auto loader.lua` | Auto-loads other addons on game join |
| `Loader.lua` | Manual addon loader |
| `Controller.lua` | Central controller for coordinating multiple addons |
| `AutoSaveFriends.lua` | Automatically saves your friend list periodically |
| `DiscordController.lua` | Discord RPC / webhook integration |
| `VehicleGod.lua` | Vehicle god-mode (invincible, no flip) |
| `afk_farm_gui.lua` | AFK farming GUI with anti-kick |
| `MusicPlayer.lua` | In-game music player |
| `music player.lua` | Alternate music player implementation |
| `car speed changger.lua` | Changes car speed cap |
| `steal stuff.lua` | Auto-steal mechanic |
| `TouchAllShards.lua` | Instantly touches/collects all shards on the map |
| `inventory_value_checker.lua` | Calculates and displays total inventory value |
| `inventory_val_calc.lua` | Lightweight inventory value calculator |
| `avatar cloner.lua` | Clones a target player's avatar appearance |
| `korblox and headless.lua` | Equips Korblox + Headless cosmetics |
| `wear_full_iron_man_suit.lua` | Equips the full Iron Man accessory set |
| `wear_iron_man_helmet.lua` | Equips just the Iron Man helmet |
| `RealisticMovement.lua` | Walk/run physics overrides for realism |
| `GripForceTest.lua` | Tests grip force values on held tools |
| `check_unanchored.lua` | Scans workspace for unanchored parts |
| `hidden_item_scanner.lua` | Scans for hidden items on the map |
| `retrieve_hidden_items.lua` | Retrieves and logs hidden item data |
| `a test.lua` | General-purpose test script |
| `rpg shit thing idk[.lua` | RPG tool experiment |
| `rpg shit thing idk[ (1).lua` | RPG tool experiment v2 |
| `rpg v2.lua` | RPG system v2 |
| `random_game.lua` | Random mini-game / fun script |
| `NanFlingV3.lua.disabled` | Disabled NaN Fling v3 (kept for reference) |
