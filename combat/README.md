# Combat Addons

Scripts for killing, bagging, stomping, arresting, and grabbing players.

| File | Description |
|------|-------------|
| `haydens auto kitten bagger 9000.lua` | Full-featured auto-bagger with adaptive/behind/below/custom position strategies, anti-bag safety, and silent-aim targeting |
| `haydens annoy bag.lua` | Lightweight annoy-bag variant |
| `auto_bag_v2.lua` | Revamped auto-bag: dropdown + silent-aim targeting, KO/crew/wall checks, sticky bagging |
| `auto bag.lua` | Original auto-bag script |
| `auto_kill_v2.lua` | Auto-kill with flamethrower mode, stomp, and void-on-kill support |
| `auto_arrest.lua` | Auto-arrest for police: instant kill / bag+knock / wait modes, cuff equip |
| `auto stomp.lua` | Simple auto-stomp on downed players |
| `auto_stomp_v2.lua` | Updated stomper with configurable delays |
| `auto_bounty_stomp.lua` | Stomp players with active bounties |
| `anti_bag.lua` | Prevents nearby players from bagging you |
| `PepperSprayKiller.lua` | Buys & equips pepper spray, glues to target, auto-stomps |
| `NeckGrabsAddon.lua` | Neck grab suite: Combo, Finisher, Void, Fling, Dismemberment tools |
| `dropkick.lua` | Dropkick animation/tool |
| `grabs.lua` | Grab utility stub |
| `winnerwinnerchickendinner.lua` | Post-kill celebration effect |
| `sticky cum.lua` | Sticky-glue attach tool |
| `sticky glue shit.lua` | Alternate sticky glue variant |
| `lumber tycoon 2 auto kill.lua` | Auto-kill adapted for Lumber Tycoon 2 |
| `haydens kitten saver 900.lua` | Kitten Saver Protector: shields owner/whitelisted players from ragebot |
| `kitten baggger` | Raw kitten-bagger source (no extension) |
| `kitten saver9000` | Raw kitten-saver source (no extension) |
