# Movement Addons

Scripts for flinging, teleporting, strafing, sliding, and bringing players.

| File | Description |
|------|-------------|
| `NanFling.lua` | NaN Fling v1 — server-wide or targeted fling via desync NaN |
| `NanFlingV2.lua` | NaN Fling v2 — optimised version with improved looping |
| `expanded_fling.lua` | Extended fling with extra targeting options and UI |
| `flingtool.lua` | Tool-based fling (equip to use) |
| `ToolFling.lua` | Alternate tool fling implementation |
| `seat_fling_improved.lua` | Seat-based fling exploit — improved stability |
| `part fling.lua` | Part-anchor fling method |
| `BringPlayer.lua` | Silent Bring — grabs target, waits for KO, returns them to you |
| `target_strafe.lua` | Orbit-strafe around silent-aim target using desync callback |
| `haydens slide.lua` | Slide movement hack |
| `grenade teleport.lua` | Teleport via grenade trajectory |
| `grenade_tp_v2.lua` | v2 grenade teleport |
| `cart_flight.lua` | Cart-based flight exploit |
| `CartControl.lua` | Enhanced cart control UI |
| `cart.lua` | Raw cart manipulation |
| `MathVFX_Addon_AllTargets.lua` | Math-based velocity VFX applied to all targets |
| `ToolGripAddon.lua` | Grip position customiser for held tools |
| `alt control.lua` | Alt-key movement control override |
| `fake kick.lua` | Fake kick animation |
| `NanFling - Copy.lua` | *(archived copy — see `_archive/`)* |
| `flingtool - Copy.lua` | *(archived copy — see `_archive/`)* |
