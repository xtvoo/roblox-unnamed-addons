# Ragebot Addons

Scripts that extend the Unnamed ragebot: whitelist management, desync visuals, anti-aim, and crew targeting.

| File | Description |
|------|-------------|
| `auto_whitelist.lua` | Auto-whitelist friends & crew; `/wl <username>` chat command; visual confirmation |
| `desync_visuals.lua` | Ghost Chams + floating icon at real server position; customisable colour & icon ID |
| `ragebot_strafe_visuals.lua` | On-screen indicator showing when ragebot strafe is active |
| `CrewTargetAddon.lua` | Adds crew-based target filtering to the ragebot |
| `CrewTargeter.lua` | Lightweight crew targeter |
| `rage bot stuff.lua` | Misc ragebot experimentation / dev notes |
| `anti aim protection.lua` | Detects incoming anti-aim and applies counter-measures |
| `Overseer.lua` | Monitors ragebot state and auto-adjusts settings |
